# Robofut32

Repositorio do projeto Robofut32, um robo de futebol desenvolvido para estudos, prototipagem e demonstracao em portfolio.

## Status

Em estruturacao inicial.

## Objetivos

- Organizar firmware, hardware, documentacao e simulacoes em um unico repositorio.
- Registrar decisoes tecnicas do projeto conforme ele evolui.
- Facilitar apresentacao do projeto no GitHub e no portfolio.
- Manter historico claro de alteracoes usando Git.
