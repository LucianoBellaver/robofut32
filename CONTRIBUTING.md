# Como contribuir

Este repositorio usa uma organizacao simples para manter o projeto facil de acompanhar.

## Fluxo recomendado

1. Crie ou edite arquivos dentro da pasta correta.
2. Rode testes ou validacoes quando existirem.
3. Use mensagens de commit curtas e objetivas.
4. Documente mudancas importantes em `docs/`.

## Padrao de commits

Exemplos:

```text
Adiciona estrutura inicial do firmware ESP32
Documenta ligacao dos motores
Atualiza fotos do prototipo
Corrige leitura do sensor frontal
```

## Organizacao

- `firmware/`: codigo dos microcontroladores.
- `hardware/`: arquivos mecanicos, eletricos e de montagem.
- `pcb/`: projetos de placa, esquemas e fabricacao.
- `docs/`: relatorios, decisoes tecnicas, fotos e referencias.
- `simulations/`: simulacoes e modelos de teste.
- `assets/`: imagens, diagramas e materiais para apresentacao.
