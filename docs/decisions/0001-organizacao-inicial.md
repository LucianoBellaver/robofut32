# 0001 - Organizacao inicial do repositorio

## Contexto

O projeto precisa separar firmware, hardware, documentacao, simulacoes e materiais visuais para facilitar manutencao e apresentacao no GitHub.

## Decisao

A estrutura inicial do repositorio sera dividida em pastas por area do projeto.

## Consequencias

- Cada parte do projeto tem um local claro.
- O historico de evolucao fica mais facil de acompanhar.
- Novos arquivos podem ser adicionados sem misturar firmware, hardware e documentacao.
