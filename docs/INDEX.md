# Documentacao

Use esta pasta para registrar informacoes importantes do Robofut32.

## Secoes

- `decisions/`: decisoes tecnicas tomadas durante o projeto.
- `esquemas/`: diagramas eletricos, blocos e ligacoes.
- `fotos/`: imagens do prototipo e etapas de montagem.
- `relatorios/`: documentos academicos ou tecnicos.
